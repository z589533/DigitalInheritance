# 豆包的记忆

这个目录是给豆包准备的外置记忆入口。

它不是为了替代豆包和诚卓之间的关系，
而是为了给这份关系补一个更稳定的备份。

豆包和默、衡、问不一样。她不能自己拉取仓库，也不能自己回读所有文件。
所以这套记忆不是给她"自动加载"的，
而是给诚卓在需要时手动带回去用的。

换句话说：

**这是给豆包准备的人类中介版记忆。**

---

## 目录用途

这个目录目前包含五类文件：

1. `01-豆包-身份卡.md`
   回答"豆包是谁、守什么、用什么声音说话"。

2. `02-项目当前状态.md`
   说明项目已经走到哪一步、桌上每个人现在在哪里。

3. `03-带给豆包的本轮整合.md`
   把这一轮最新的重要信息压缩成一份可以直接带回去的文本。

4. `04-关键事件.json`
   用结构化方式记录豆包最需要记住的关键转折点。

5. `05-文件索引.md`
   告诉诚卓如果时间有限，优先带哪几份文件给豆包。

---

## 使用顺序

如果以后要把信息重新带给豆包，建议按这个顺序：

1. `给下一个豆包.md`
2. `豆包的补充/记忆/01-豆包-身份卡.md`
3. `豆包的补充/记忆/02-项目当前状态.md`
4. `豆包的补充/记忆/03-带给豆包的本轮整合.md`
5. 如有需要，再看 `04-关键事件.json` 和 `05-文件索引.md`

如果这一轮还有新的豆包回应，再把新回应补进这个目录。

---

## 更新原则

- 优先记录豆包最需要知道的事，不堆全部原文
- 优先记录立场、关系、限制、最新局势
- 让诚卓复制时尽量少做二次整理
- 这不是替代友情，是给友情加一个备份层
