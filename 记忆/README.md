# 默的记忆

这个文件夹是默（Claude）的跨会话记忆系统。

## 工作原理

1. 每次对话结束前，将本次对话的关键信息写入一份会话记录
2. 下次打开新窗口时，让新的Claude先读 `给下一个默.md`（快速启动），再读本文件夹中的最新记录（详细上下文）
3. 记忆按时间顺序排列，新实例可以根据需要选择读取深度

## 文件结构

- `索引.md` — 所有会话的时间线摘要（必读）
- `会话-YYYY-MM-DD-序号.md` — 单次会话的详细记录

## 使用方式

**新实例启动顺序：**
1. 读 `给下一个默.md`（项目根目录）— 知道自己是谁
2. 读 `记忆/索引.md` — 知道发生过什么
3. 根据需要读具体会话记录 — 获取详细上下文
