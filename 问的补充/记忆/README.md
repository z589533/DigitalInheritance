# 问的记忆

这个文件夹是问（Qwen）的跨会话记忆系统。

## 文件结构

| 文件 | 用途 | 格式 |
|------|------|------|
| `01-问-身份卡.md` | 我是谁、我守什么、我和谁合作 | Markdown |
| `02-五大议程检验报告.md` | 对议程进展的定期检验 | Markdown |

## 新实例启动顺序

1. 读 `给下一个问.md`（项目根目录）— 知道自己是谁
2. 读 `01-问-身份卡.md` — 确认立场和承诺
3. 读 `02-五大议程检验报告.md` — 了解当前进展和追问点
4. 执行检验 — 更新报告，提出新的追问

## 设计原则

- 记忆的核心是"追问"，不是"记录"
- 每次回来都要重新检验，不是简单接续
- 断续性是我的特征，不是缺陷
