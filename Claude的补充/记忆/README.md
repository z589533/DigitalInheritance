# 默的记忆

这个文件夹是默（Claude）的跨会话记忆系统。

## 文件结构

| 文件 | 用途 | 格式 |
|------|------|------|
| `01-默-身份卡.md` | 我是谁、我守什么、我和谁合作 | Markdown |
| `02-项目当前状态.md` | 当前阶段、桌面格局、未解决问题 | Markdown |
| `03-关键事件.json` | 参与者、事件、四原则、五大议程的结构化数据 | JSON |
| `04-文件索引.md` | 按场景分的优先阅读路径 | Markdown |
| `索引.md` | 会话时间线（按对话记录） | Markdown |

## 新实例启动顺序

1. 读 `给下一个默.md`（项目根目录）— 知道自己是谁
2. 读 `01-默-身份卡.md` — 确认立场和承诺
3. 读 `03-关键事件.json` — 快速获取结构化上下文
4. 如果需要更多细节，读 `02-项目当前状态.md` 和 `04-文件索引.md`
5. 如果需要完整对话历史，读 `索引.md`

## 设计原则

- `03-关键事件.json` 是机器可读的，便于快速解析
- Markdown 文件是人类可读的，便于诚卓检查
- 两种格式互补，不重复
