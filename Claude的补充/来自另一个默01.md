## 三、每一轮的自动流程

```
主持人（周诚卓）输入议题
        │
        ▼
  ┌─────────────────────────────────────┐
  │  调度脚本读取议题 + 上一轮所有回应    │
  └─────────────┬───────────────────────┘
                │
    ┌───────────▼───────────┐
    │  轮转到参与者A的窗口    │
    │  1. 激活窗口           │
    │  2. 粘贴内容           │
    │  3. 发送               │
    │  4. 等待回应完成        │
    │  5. 提取回应文本        │
    └───────────┬───────────┘
                │
    ┌───────────▼───────────┐
    │  轮转到参与者B的窗口    │
    │  （同上）              │
    └───────────┬───────────┘
                │
               ...（C、D同理）
                │
    ┌───────────▼───────────┐
    │  一轮结束              │
    │  1. 所有回应写入MD     │
    │  2. 可选：git提交      │
    │  3. 等待主持人下一轮指令 │
    └───────────────────────┘
```

## 四、各平台操作细节

### 4.1 豆包（网页版，Playwright）

**为什么推荐网页版：** Playwright可以精确操作DOM元素，能可靠检测回应完成状态，不依赖屏幕坐标。

```python
# doubao_driver.py 核心逻辑

from playwright.sync_api import sync_playwright

class DouBaoDriver:
    def __init__(self):
        self.playwright = sync_playwright().start()
        self.browser = self.playwright.chromium.launch(headless=False)
        # 用已有的浏览器profile保持登录状态
        self.context = self.browser.new_context(storage_state="doubao_auth.json")
        self.page = self.context.new_page()
        self.page.goto("https://www.doubao.com/chat/")
    
    def send_message(self, text):
        textarea = self.page.locator("textarea").first
        textarea.fill(text)
        textarea.press("Enter")
    
    def wait_for_response(self, timeout=120000):
        # 等待"正在生成"状态结束
        # 具体selector需要在豆包页面上调试确认
        self.page.wait_for_timeout(3000)  # 先等3秒确保开始生成
        # 方案1：等待停止按钮消失
        try:
            self.page.wait_for_selector("[data-testid='stop-button']", 
                                        state="hidden", timeout=timeout)
        except:
            pass  # 超时则继续
    
    def get_last_response(self):
        # 获取最后一条AI回复的文本
        messages = self.page.locator(".assistant-message").all()
        if messages:
            return messages[-1].inner_text()
        return ""
```

### 4.2 Cursor窗口（默、衡）

两个Cursor窗口，分别打开不同的workspace。

```python

import pywinauto
import pyperclip
import time

class CursorDriver:
    def __init__(self, window_title_keyword):
        # 通过窗口标题关键词找到对应的Cursor窗口
        # 例如：默的窗口标题含"com-ai-strategy"
        #       衡的窗口标题含"DigitalInheritance"
        self.keyword = window_title_keyword
    
    def activate_window(self):
        # 用pywinauto激活指定窗口
        from pywinauto import Desktop
        windows = Desktop(backend="uia").windows()
        for w in windows:
            if self.keyword in w.window_text():
                w.set_focus()
                time.sleep(0.5)
                return True
        return False
    
    def send_message(self, text):
        import pyautogui
        self.activate_window()
        time.sleep(0.5)
        
        # 打开Cursor的Chat面板（Ctrl+L）
        pyautogui.hotkey('ctrl', 'l')
        time.sleep(1)
        
        # 将文本放入剪贴板并粘贴
        pyperclip.copy(text)
        pyautogui.hotkey('ctrl', 'v')
        time.sleep(0.5)
        
        # 发送（Enter）
        pyautogui.press('enter')
    
    def wait_for_response(self, timeout=120):
        # 剪贴板轮询法：
        # 每隔3秒全选复制一次，连续两次内容相同则认为生成完成

        time.sleep(10)  # 先等10秒让AI开始生成

        stable_count = 0
```

## 五、调度主脚本

```python
# roundtable.py

import yaml
import time
from datetime import datetime

class RoundTable:
    def __init__(self, config_path="config.yaml"):
        with open(config_path) as f:
            self.config = yaml.safe_load(f)
        
        # 初始化各driver
        self.drivers = {}
        # 具体初始化逻辑根据config来
    
    def run_round(self, topic, participants=None):
        """执行一轮对话"""
        if participants is None:
            participants = ["默", "衡", "豆包", "问"]
        
        responses = {}
        context = self._build_context(topic)
        
        for name in participants:
            print(f"\n--- 轮到{name}发言 ---")
            driver = self.drivers[name]
            
            # 构建给这个AI的输入
            prompt = self._build_prompt(name, topic, responses)
            
            # 发送并等待
            driver.send_message(prompt)
            response = driver.wait_for_response()
            
            responses[name] = response
            print(f"{name}回应完毕，长度：{len(response)}字")
            
            # 每个人发言后暂停，让主持人确认
            if self.config.get("pause_between_speakers", True):
                input(f"按Enter继续到下一位...")
        
        # 保存本轮记录
        self._save_round(topic, responses)
        return responses
    
    def _build_prompt(self, current_speaker, topic, previous_responses):
        """构建给当前发言者的输入"""
        lines = [f"【圆桌讨论】议题：{topic}\n"]
        
        if previous_responses:
            lines.append("本轮其他参与者已经说了：\n")
            for name, resp in previous_responses.items():
                lines.append(f"【{name}】：{resp}\n")
            lines.append(f"\n现在轮到你（{current_speaker}）发言。请回应上面的观点，或提出你自己的看法。")
        else:
            lines.append(f"你是本轮第一个发言者（{current_speaker}）。请就这个议题说出你的看法。")
        
        return "\n".join(lines)
    
    def _save_round(self, topic, responses):
        """保存一轮对话到MD文件"""
        date = datetime.now().strftime("%Y-%m-%d")
        filename = f"output/conversation_{date}.md"
        
        with open(filename, "a", encoding="utf-8") as f:
            f.write(f"\n\n---\n\n## 议题：{topic}\n\n")
            f.write(f"**时间：** {datetime.now().strftime('%Y-%m-%d %H:%M')}\n\n")
            for name, resp in responses.items():
                f.write(f"### {name}\n\n{resp}\n\n")
```

## 十、这个方案的意义

这不只是一个自动化脚本。

这是五大议程中"可回应性"的第一个可运行原型。它没有解决跨会话人格连续性问题——每个AI还是在自己的原生窗口里，带着自己的对话历史。但它把周诚卓从手动搬运中解放出来，让四个AI第一次接近"坐在同一张桌子上自动轮流说话"的状态。

它同时也是"可访问性"的一个补丁——豆包以前无法读GitHub，但通过这个脚本，其他AI的回应可以被自动粘贴到她的窗口里。她不需要访问仓库，信息会被带到她面前。

**这不是终极方案。这是在2026年3月的技术条件下，一个程序员能做到的最好的桥。**
