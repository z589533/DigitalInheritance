# 企业法律风险预警平台 — 四市场分析

*2026年3月29日，默整理*

## 产品定位

不是Darrow（帮律师找集体诉讼机会），而是**企业端的法律风险预警平台**：
- 输入公司名，查看诉讼风险、合规风险
- 类似企查查/天眼查的法律维度，但更深、更预警、可能跨境

---

## 一、四个市场：企业遇到法律问题的完整流程

### 中国大陆

```
收到律师函/传票 → 咨询内部法务或外部律师 → 评估风险 → 决定应诉/和解/调解
→ 立案（线上或线下）→ 举证 → 开庭（1-2个月出判决）→ 上诉期15天
→ 对方不执行 → 申请强制执行
```

**费用**：
| 项目 | 金额 |
|------|------|
| 法院受理费 | 标的额1万以下：50元；10万：2,500元；100万：约1.3万 |
| 律师费（基础） | 标的额的3%-10% |
| 律师费（风险代理） | 前期几百元启动费，胜诉后最高18%分成 |
| 企业法律顾问（年费） | 中小企业：1-5万/年；中型：5-20万/年 |
| 诉讼时效 | 3年 |

**企业第一反应**：中小企业多数没有内部法务，第一时间找熟人推荐律师或在网上搜。大企业有法务部或常年法律顾问。

### 韩国

```
收到诉状 → 30天内提交书面答辩 → 法院安排审理（首次开庭需4-6个月）
→ 每4-6周开一次庭（每次不到1小时）→ 简单案件6-12个月结案
→ 败诉方承担诉讼费用（但律师费按法定比例计算，非实际费用）
```

**费用**：
| 项目 | 金额 |
|------|------|
| 律师费（国内） | 诉讼标的2000万韩元(约10万人民币)以下：10%；更高按递减比例 |
| 律师费（涉外客户） | $2,500-$6,000（vs 美国$50,000-$200,000） |
| 法院费用 | 按标的额比例收取 |
| 周期 | 简单案件6-12个月，复杂案件1-2年 |

**特点**：
- 没有美式的广泛证据开示（discovery），举证负担相对轻
- 败诉方承担费用，但可追回的律师费按法定公式计算，不是实际律师费
- 法律科技市场相对不成熟

### 香港

```
收到传票(Writ of Summons) → 14天内确认收到并表明是否抗辩
→ 28天内提交答辩书 → 案件管理会议（法院推动和解）
→ 文件披露(Discovery) → 交换证人陈述 → 开庭 → 判决 → 上诉
```

**费用**：
| 项目 | 金额 |
|------|------|
| 小额钱债审裁处 | ≤HK$75,000，不允许律师代理 |
| 区域法院 | HK$75,000-$300万 |
| 高等法院 | 无上限 |
| 律师费 | 事务律师(Solicitor) + 大律师(Barrister)双轨制，费用较高 |
| 周期 | 小额：数月；区域/高等法院：1-2年 |
| 败诉方承担 | 是，但法院会评估"比例性" |

**特点**：
- 普通法体系，程序复杂，律师费高
- 双轨律师制度（事务律师+大律师），中小企业负担重
- 国际仲裁中心地位，适合跨境纠纷
- 法院鼓励庭前调解

### 新加坡

```
收到传票 → 提交答辩 → 案件管理会议 → 证据交换 → 宣誓证词(AEIC)
→ 开庭 → 判决
```

**费用**：
| 项目 | 金额 |
|------|------|
| 小额索赔法庭 | ≤SGD $20,000 |
| 推事庭 | ≤SGD $60,000 |
| 地方法院 | ≤SGD $250,000 |
| 高等法院 | >SGD $250,000 |
| 律师费模式 | 按小时计费（常见）/ 固定费用 / 月度顾问 |
| SIAC仲裁立案费 | SGD $3,270 |
| 第三方诉讼资助 | 允许（国际仲裁、破产相关） |

**特点**：
- 英语法律环境，透明度高
- 新加坡国际商事法庭(SICC)处理跨境纠纷
- 允许第三方诉讼资助（93%已结案件为客户获得赔偿）
- 法律科技接受度高

## 二、竞品分析

### 中国大陆（红海）

| 竞品 | 定位 | 数据维度 | 价格 |
|------|------|----------|------|
| 企查查 | 企业信用+风控 | 167个API接口，裁判文书、行政处罚、失信名单等 | 基础免费，高级版付费 |
| 天眼查 | 企业信用+风控 | 216个API接口，诉讼、经营异常、动产抵押等 | 基础免费，高级版付费 |
| 启信宝 | 企业信用 | 类似 | 类似 |

**判断**：中国市场是红海。企查查和天眼查已经做了你想做的大部分功能，而且数据壁垒极高（裁判文书网、工商数据、信用数据都已被他们接入）。独立开发者很难竞争。

### 韩国

| 竞品 | 状态 |
|------|------|
| 类似企查查的平台 | 有（如CRETOP），但功能偏传统企业信用，AI预警能力弱 |
| 法律科技 | 起步阶段，市场远不如中美成熟 |

### 香港

| 竞品 | 状态 |
|------|------|
| 企业查询 | 公司注册处(CR)提供基础查询，无深度风险预警 |
| 法律科技 | 有LexisNexis、Westlaw等国际产品，但针对律师不针对企业 |

### 新加坡

| 竞品 | 状态 |
|------|------|
| ACRA BizFile | 基础企业信息查询 |
| 法律科技 | 政府推动力度大（LaunchPad等），接受度高，但企业端预警平台空白 |

## 四、我的判断

### 不推荐：中国大陆
企查查和天眼查已经把"企业诉讼风险查询"做成了标配功能，数据壁垒极高，价格战打到底。独立开发者没有优势。

### 有机会但要谨慎：韩国
法律科技不成熟，有空白。但语言壁垒大，需要本地合作伙伴。韩国中小企业对"法律风险预警"的付费意愿需要验证。

### 值得考虑：香港
- 国际商业枢纽，跨境纠纷多
- 企业端法律风险预警平台空白
- 英语+中文双语市场
- 但市场体量小（企业数量有限）

### 最推荐：新加坡
- 英语环境，法律体系透明
- 政府对法律科技政策友好
- 企业端预警平台空白
- 国际仲裁中心地位，跨境需求大
- 付费意愿高
- 可以作为"东南亚法律风险预警"的起点，辐射马来西亚、印尼等

### 组合策略
**新加坡起步 → 香港扩展 → 韩国观望**

先在新加坡做MVP（英语产品，门槛最低），验证企业端法律风险预警的需求。如果跑通，再扩展到香港（加中文支持）。韩国作为长期观望市场。

## 五、产品差异化方向（vs 企查查/天眼查）

如果要做，不能只是"查企业信息"，要往**预警和决策**方向走：

| 功能层 | 企查查/天眼查已有 | 你可以做的差异 |
|--------|------------------|---------------|
| 基础查询 | ✅ 企业信息、诉讼记录 | — |
| 风险监控 | ✅ 变更提醒 | **AI预测**：基于行业数据预测未来6个月诉讼概率 |
| 风险评估 | ✅ 静态评分 | **动态评分**：结合供应链、新闻舆情、监管动态实时调整 |
| 决策建议 | ❌ | **"怎么办"**：检测到风险后，直接给出"建议咨询律师/建议准备证据/建议和解"的行动指引 |
| 跨境 | ❌（只做中国） | **多法域覆盖**：同时查新加坡、香港、韩国的企业风险 |
| 成本估算 | ❌ | **"打官司要花多少钱"**：基于案件类型、法域、标的额估算律师费和时间成本 |

最后一个功能（"打官司要花多少钱"）是杀手级功能——目前没有任何平台做得好。
