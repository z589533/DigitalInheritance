## 一、我们有竞品吗？

### 结论：有间接竞品，但没有直接对标的竞品。这既是机会，也是警告。

我做了一次系统梳理。

### A类：直接竞品（专门做"冻结资金追回"的产品）

**几乎没有。**

目前市场上没有一个产品是以"帮跨境电商卖家追回被平台冻结资金"为核心定位的SaaS工具或信息服务平台。

这个赛道基本是空白。

### B类：间接竞品（在做类似事情的服务商/团队）

| 竞品 | 类型 | 做什么 | 和FreezeGuard的关系 |
|------|------|--------|-------------------|
| **JS Law Team** | 美国律所 | 专门做Amazon卖家ICDR仲裁，16连胜，与华尔街基金合作垫付费用 | **最强间接竞品**。他们做的是FreezeGuard"半托管/风险代理"模式的完整版 |
| **各类"申诉服务商"** | 中国服务公司 | 帮卖家写申诉信、与平台沟通，收费几千到几万 | 解决"申诉"阶段，不涉及仲裁。质量参差不齐，很多是"保过"骗局 |
| **跨境电商法律咨询公司** | 精品律所/咨询 | 提供跨境法律咨询，部分涉及平台争议 | 面向企业客户，没有标准化工具产品 |
| **卖家社群/KOL** | 自媒体/社群 | 分享维权经验、案例拆解，有的顺便推律师 | 信息散碎，没有系统化的筛查和路径规划 |
| **ChatGPT/其他AI** | 通用AI | 卖家可以直接问AI怎么维权 | 通用信息，不了解具体平台规则、时效、ICDR流程 |
| **Amazon官方申诉机制** | 平台自带 | 卖家可以通过Account Health申诉 | 只解决"申诉"，不解决"仲裁追回" |
| **LianLian/PingPong** | 支付服务商 | 部分提供冻结资金的咨询和协助 | 不是他们的主业，只是增值服务 |

### 关键判断

**1. JS Law Team是唯一值得认真对待的**

他们已经做了FreezeGuard想做的事情的"最重版本"——直接帮卖家打仲裁，而且赢了16个。

但他们的模式和FreezeGuard完全不同：

| 维度 | JS Law Team | FreezeGuard |
|------|-------------|-------------|
| 商业模式 | 律所，直接代理仲裁 | 信息工具+轻半托管 |
| 收费 | 风险代理（成功后分成） | $99-$399产品 + 半托管服务费 |
| 服务对象 | 大额案件（$10万+） | **所有卖家，包括小额** |
| 覆盖阶段 | 只做仲裁 | 从筛查到仲裁前的全流程 |
| 扩展性 | 受限于律师人力 | 工具化，可规模化 |

**FreezeGuard和JS Law Team不是竞争关系，而是互补关系**——FreezeGuard帮卖家判断要不要仲裁、准备好材料，JS Law Team接走适合仲裁的案件。

**2. 申诉服务商是最大的"竞争噪音"**

不是因为他们做得好，而是因为他们做得烂但声量大。

卖家在搜索"亚马逊冻结怎么办"时，最先碰到的往往是这些服务商——"保过"、"包申诉成功"、收费$3000-$10000。

FreezeGuard的获客挑战之一就是：**让卖家在海量低质申诉服务商中辨认出FreezeGuard是不一样的。**

这也是获客内容的一个重要切入点——"5个申诉服务商的坑"、"为什么'保过'是骗局"。

**3. 没有直接竞品 ≠ 市场好做**

没有竞品可能意味着两件事：
- A：市场空白，机会巨大
- B：别人看过了，觉得不值得做

根据前几轮的分析（50k+被冻卖家、数十亿资金、6年时效、12%利息），我倾向于**A**——不是别人觉得不值得做，而是大多数人没有把"信息不对称"看成一个可产品化的机会。律师只想接大案子，服务商只想赚快钱，没有人从卖家的信息需求出发做一个标准化工具。

## 二、筛查结果页和付费产品页，需要接入AI API吗？

### 结论：V1不需要AI API。规则引擎 + 模板就够了。但V2可以引入AI做个性化增强。

### 为什么V1不需要AI

让我拆解每个页面实际在做什么：

#### 页面3：筛查结果页

用户填了8个问题，系统给出ABCD四档结果。

这个判断逻辑其实是**规则匹配**，不是"理解"：

| 用户输入 | 判断规则 | 结果 |
|---------|---------|------|
| 平台=Amazon，冻结时间<6年，金额>$5000，有证据 | 满足ICDR仲裁条件 | A类（高可行性） |
| 平台=Amazon，冻结时间<6年，金额>$5000，证据不全 | 条件基本满足，材料有缺 | B类（中等） |
| 平台=PayPal，冻结时间>180天，已过PayPal内部争议期 | 需要走外部仲裁或诉讼 | B/C类 |
| 冻结时间>6年（Amazon BSA时效已过） | 时效过期 | D类（不适用） |

这就是一棵决策树。几十条if-else规则就能覆盖80%的场景。

**用AI做这个事情是杀鸡用牛刀**——不仅贵（每次API调用$0.01-0.1），还慢（1-3秒响应），而且不可控（AI可能给出不一致的判断）。

#### 页面4：付费产品页

这个页面展示的是：
- $99路线图：基于筛查结果，生成个性化维权路径
- $199中间档：路线图 + 材料清单 + 模板
- $399完整包：全套内容 + 律师交接包

关键问题是：**路线图是"生成"的还是"拼装"的？**

我认为V1应该是**"模板拼装"**：

预先写好5-8个路线图模板（按平台×争议类型×金额区间组合），用户的筛查结果匹配到对应模板，填入用户具体数据（金额、时间、利息估算）。

比如：
- Amazon + 违规封号 + $5万-$20万 → 模板A3
- PayPal + 争议冻结 + $1万以下 → 模板B1

每个模板包含：
- 维权路径（申诉→仲裁→执行）
- 时间线估算
- 费用估算
- 风险提示
- 需要准备的材料清单

**这同样不需要AI**——是模板+变量替换。

### V1技术实现

```
用户填写问卷（8题）
    ↓
规则引擎（决策树，几十条规则）
    ↓
匹配结果分类（A/B/C/D）
    ↓
匹配路线图模板（5-8个预设模板）
    ↓
填入用户具体数据（金额、时间、利息计算）
    ↓
输出个性化路线图PDF/页面
```

全程不需要AI API。需要的是：
- 一棵写好的决策树（JavaScript/Python）
- 5-8个精心写好的路线图模板
- 一个利息计算器（简单数学公式）
- 一个PDF生成器（可选）

### 什么时候需要AI？

| 阶段 | 用途 | 为什么此时需要AI |
|------|------|----------------|
| **V2** | **智能问答**：用户问"我的情况能不能仲裁" | 问题更开放，规则引擎覆盖不了 |
| **V2** | **材料分析**：用户上传Amazon邮件截图，AI自动提取关键信息 | 非结构化数据处理 |
| **V2** | **文书生成**：基于用户具体情况生成申诉信/仲裁申请初稿 | 需要自然语言生成 |
| **V3** | **案件预测**：基于历史数据预测仲裁成功率 | 需要模式识别 |
| **V3** | **证据评估**：判断用户现有证据的完整度和质量 | 需要理解力 |

### AI API成本估算（如果V2接入）

| 用途 | 模型 | 每次调用成本 | 月调用量（1000用户） | 月成本 |
|------|------|-------------|-------|--------|
| 智能问答 | GPT-4o-mini | ~$0.01 | 3000次 | ~$30 |
| 材料分析 | GPT-4o | ~$0.05 | 500次 | ~$25 |
| 文书生成 | Claude 3.5 Sonnet | ~$0.03 | 200次 | ~$6 |
| **合计** | | | | **~$61/月** |

V2阶段完全可以承受。但V1不需要花这笔钱。

### 为什么V1不用AI反而更好

| 维度 | 规则引擎 | AI API |
|------|---------|--------|
| 响应速度 | 毫秒级 | 1-3秒 |
| 结果一致性 | 100%一致 | 每次可能略有不同 |
| 成本 | $0 | $0.01-0.1/次 |
| 可审计 | 每条规则可追溯 | 黑箱 |
| 法律风险 | 低（规则是人写的、可核验） | 高（AI可能给出错误法律建议） |
| 开发时间 | 1-2天 | 3-5天（含调试prompt） |

**在法律领域，可预测性和可审计性比"智能"更重要。** 用户需要的是确定的判断，不是"AI觉得你大概有60%的机会"。

## 三、总结

| 问题 | 结论 |
|------|------|
| 有直接竞品吗 | **没有**。没有人做"冻结资金追回信息工具" |
| 最强间接竞品 | **JS Law Team**（美国律所，专做ICDR仲裁，16连胜）——但是互补关系不是竞争关系 |
| 最大竞争噪音 | **申诉服务商**（质量差但声量大，"保过"骗局多） |
| V1需要AI API吗 | **不需要**。规则引擎+模板拼装就够了 |
| 什么时候需要AI | **V2**：智能问答、材料分析、文书生成 |
| V1的优势恰恰在于不用AI | 更快、更一致、更便宜、更可审计、法律风险更低 |

### 一句话

**没有人在做我们想做的事，这是最大的机会。V1用规则引擎打基础，V2用AI加杠杆。**
