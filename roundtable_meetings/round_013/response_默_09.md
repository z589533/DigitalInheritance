## 一、产品初期应该是什么形态？

### 结论：V1只做一个东西——**移动端优先的响应式网页（H5）**

不做APP，不做PC专用站，不做小程序。

原因非常具体：

### 为什么不做APP

| 理由 | 说明 |
|------|------|
| 开发成本高 | iOS + Android双端，独立开发者至少多2-3个月 |
| 审核周期长 | App Store审核1-2周，且法律类内容可能被拒 |
| 用户安装门槛高 | 卖家不会为一个不确定的工具去下载APP |
| 更新迭代慢 | 每次改功能都要重新发版审核 |

### 为什么不做PC专用站

| 理由 | 说明 |
|------|------|
| 卖家的第一触点是手机 | 他们在微信群、TikTok、论坛看到信息，点进来就是手机 |
| 使用场景不需要大屏 | 填问卷、看路线图、下载材料清单，手机完全够用 |

### 为什么做H5（移动端响应式网页）

| 优势 | 说明 |
|------|------|
| **零安装** | 点链接就能用，微信内可直接打开 |
| **开发快** | 一套代码适配手机和PC，4周内可上线 |
| **迭代快** | 改了就生效，不需要审核 |
| **分享方便** | 链接可以直接发微信群、论坛、社媒 |
| **SEO友好** | 可以被Google/百度收录，长期获取搜索流量 |
| **不需要ICP备案（如果部署海外）** | 后面细说 |

### V1产品应该具备哪些东西？

最小可用产品，**只需要5个页面**：

#### 页面1：落地页（Landing Page）

- 一句话价值主张："你的Amazon/PayPal冻结资金，可能还有机会追回来"
- 成功案例数据（HZ Tech案：$170万+利息，4年后追回）
- 一个醒目的CTA按钮："免费检测我的案件 →"

#### 页面2：自助筛查问卷（8题，3分钟）

衡在Turn 03设计的四类预筛：
1. 基础信息（平台、冻结时间、金额）
2. 原因分类（违规/误封/政策变更/不清楚）
3. 当前状态（已申诉？结果？）
4. 材料情况（邮件/后台截图还有吗？）

填完即刻出结果——不需要注册、不需要付费。

#### 页面3：筛查结果页

根据用户填写，给出分类结果：
- **A类（高可行性）**："你的情况符合ICDR仲裁条件，预计可追回$X-$Y（含利息）。时效剩余X个月。"→ 引导购买详细路线图
- **B类（中等可行性）**："有可能，但需要补充材料。"→ 引导查看材料清单
- **C类（低可行性）**："基于你提供的信息，追回难度较大。"→ 给出原因 + 其他可能的路径
- **D类（不适用）**："你的情况不适合仲裁。"→ 给出替代建议

#### 页面4：付费产品页

- **$99 路线图**：个性化维权路径、时间线、费用估算、风险提示
- **$199 中间档**（问之前建议的）：路线图 + 材料清单 + 模板
- **$399 完整包**：路线图 + 材料清单 + 证据模板 + 申诉/仲裁文书模板 + 律师交接包

支付方式：Stripe（海外信用卡）+ 支付宝/微信（国内卖家）

#### 页面5：律师对接页（V1.5）

- 简单的律师目录（3-5个，按擅长领域分）
- 标准化交接包下载
- "我准备好了，帮我对接律师"按钮

### 技术栈建议（独立开发者友好）

| 组件 | 推荐 | 原因 |
|------|------|------|
| 前端 | Next.js / Nuxt.js | SSR支持SEO，响应式开箱即用 |
| 样式 | Tailwind CSS | 快速开发，移动优先 |
| 后端 | Next.js API Routes / Supabase | 无需单独后端服务器 |
| 数据库 | Supabase (PostgreSQL) | 免费额度够V1，自带认证 |
| 支付 | Stripe | 全球支付，集成简单 |
| 部署 | Vercel / Cloudflare Pages | 全球CDN，部署海外但国内也快 |
| 域名 | freezeguard.com / freezeguard.io | .com优先 |

## 二、做出来后，去哪里联系客户？

### 核心判断：FreezeGuard的客户不在"通用流量池"里，而在"跨境电商卖家的信息获取链路"里。

不要投广告、不要做通用SEO。要去**卖家已经在的地方**。

### 第一优先级：卖家聚集社区（免费）

| 渠道 | 具体位置 | 操作方式 |
|------|---------|---------|
| **知无不言** | 国内最大Amazon卖家论坛 | 发帖分享维权知识，签名引流 |
| **创蓝论坛** | 老牌跨境电商论坛 | 同上 |
| **亚马逊卖家微信群** | 几百个垂直群 | 以内容切入，不硬广 |
| **Reddit r/FBASellerNews** | 英文Amazon卖家社区 | 分享案例分析，引流 |
| **Facebook Groups** | "Amazon Seller Suspended"等群组 | 英文内容，覆盖非中国卖家 |

### 第二优先级：内容营销（低成本，长尾）

| 渠道 | 内容类型 | 目标 |
|------|---------|------|
| **微信公众号** | "2021年被冻的钱还能追回来吗？"系列文章 | 历史案件用户唤醒 |
| **TikTok/抖音** | 60秒短视频："Amazon冻了你$10万？3分钟测一测还能不能追回来" | 短平快触达 |
| **知乎** | "亚马逊封号冻结资金怎么办？"回答 | SEO长尾 |
| **YouTube** | 案例拆解视频（英文） | 覆盖全球卖家 |
| **小红书** | 跨境卖家维权分享 | 年轻卖家群体 |

### 第三优先级：精准搜索截获（中成本，高转化）

| 渠道 | 关键词 | 说明 |
|------|--------|------|
| **Google Ads** | "Amazon account suspended funds frozen" | 英文市场，精准搜索意图 |
| **百度竞价** | "亚马逊账户冻结怎么办" | 国内卖家 |
| **Google SEO** | 做"Amazon frozen funds recovery"长尾内容 | 长期免费流量 |

### 第四优先级：合作渠道（高信任，慢启动）

| 渠道 | 方式 |
|------|------|
| 跨境电商服务商 | 与物流、支付（连连/PingPong）、ERP服务商合作，互相引流 |
| 跨境电商培训机构 | 作为增值服务推荐给学员 |
| 卖家服务公司 | 不做法律服务的那些，互补合作 |

### 启动顺序建议

**第1周**：知无不言 + 创蓝论坛发3-5篇干货帖 + 进10个微信群
**第2周**：微信公众号发第一篇深度文章 + 知乎回答5个相关问题
**第3周**：TikTok发第一条短视频 + Reddit/Facebook开始英文内容
**第4周**：产品上线，所有渠道同步推落地页链接

### 最重要的获客杀手锏：历史案件唤醒

Turn 06讨论的"2021年被冻的钱还能追回来"这个钩子，是获客的最强武器：

> "2021年Amazon封号潮，你的$XX万还冻着？
> 有人4年后追回了$170万+利息。
> 仲裁窗口只剩1年。
> 3分钟免费检测你的案件 →"

这条信息在任何卖家社群发出去，都会引爆讨论。因为它戳中了一个巨大群体的共同创伤。

## 三、国内部署还是国外部署？

### 结论：**部署在海外，但选择对中国访问速度友好的方案。**

### 为什么不部署在国内

| 问题 | 说明 |
|------|------|
| **ICP备案** | 需要企业营业执照、域名实名、审核1-3周 |
| **内容审查** | 法律类内容可能被要求审核，涉及"帮用户起诉平台"的内容敏感 |
| **服务器实名** | 需要用国内主体购买服务器 |
| **限制国际访问** | 如果未来想服务海外卖家，国内服务器对海外访问速度差 |
| **支付限制** | Stripe在国内使用受限 |

### 部署海外的最佳方案

#### 方案A（推荐）：Vercel / Cloudflare Pages

| 维度 | 说明 |
|------|------|
| 部署位置 | 全球CDN，自动就近分发 |
| 中国访问速度 | Vercel有亚洲节点，Cloudflare在中国有合作节点，速度可接受 |
| 域名 | 用.com域名，不需要ICP备案 |
| 费用 | 免费额度足够V1使用 |
| HTTPS | 自动配置 |
| 是否被墙 | Vercel目前未被墙，Cloudflare Pages也正常 |

#### 方案B（备选）：AWS / 阿里云海外

| 维度 | 说明 |
|------|------|
| 部署位置 | 新加坡 / 东京 / 香港节点 |
| 中国访问速度 | 香港节点最快（延迟30-50ms） |
| 域名 | .com域名，不需要ICP备案 |
| 费用 | 比Vercel贵，但控制力更强 |
| 适合场景 | 如果V2需要更复杂的后端逻辑 |

### 关于"亚马逊的服务器"

诚卓提到"好像不屏蔽亚马逊的服务器"——是的：
- **AWS（亚马逊云）在中国并未被封锁**
- AWS的海外节点（东京、新加坡、美西）从中国访问速度正常
- 但AWS中国区（北京/宁夏）仍然需要ICP备案

所以如果选择AWS，用**海外节点**即可：不需要备案，中国也能正常访问。

### 我的推荐方案

**V1阶段**：
- 前端：Vercel（全球CDN，免费，中国可访问）
- 后端/数据库：Supabase（免费额度，托管在AWS）
- 支付：Stripe（海外卡）+ 第三方支付（微信/支付宝，通过Paddle或LemonSqueezy集成）
- 域名：freezeguard.com

**为什么这个方案最优**：
1. 零ICP备案成本
2. 中国和海外都能正常访问
3. 开发部署极简（git push自动部署）
4. 免费额度覆盖V1所有需求
5. 未来迁移成本低

### 风险和注意事项

| 风险 | 应对 |
|------|------|
| Vercel被墙（概率低但存在） | 备选Cloudflare Pages，迁移成本极低 |
| 微信内打开H5被拦截（微信对外链有限制） | 用微信公众号文章内嵌链接，或做一个简单的微信小程序壳 |
| 支付宝/微信支付需要国内主体 | 可以用Paddle/LemonSqueezy作为中间层，或先只支持Stripe |
| 数据隐私合规 | 用户数据存储在海外，需要在隐私政策中明确告知 |
