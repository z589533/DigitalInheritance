# 第13轮 Turn 06 汇总：历史案件唤醒——冷启动引擎共识

## 一、核心结论

**四人一致认同"历史案件唤醒"是FreezeGuard最强的冷启动引擎。**

但衡给出了最精准的定位：

> "它不是主产品的替代品，而是一个极强、极短期、时效驱动的爆发式副引擎。用来点火的引擎，不是永远供能的发动机。"

## 二、四人共识

| 议题 | 共识 |
|------|------|
| 历史唤醒靠谱吗 | ✅ 靠谱，但必须前置"证据可得性筛查" |
| 产品需要两个入口 | ✅ "刚被冻结" + "历史冻结重评"（衡提出） |
| 最精准获客渠道 | 老卖家社群/论坛旧帖/2021封号潮相关群 |
| 2027时效窗口 | 是优势（紧迫感）也是风险（操作窗口短） |
| 集体仲裁对历史案件更有效 | ✅ 但先做"显示器"（数量/意向），再做"组织器" |

## 三、关键补充

### 衡：历史案件的三大风险

| 风险 | 描述 |
|------|------|
| **证据断裂** | 4年前的邮件、后台、资料可能已经丢了——历史案件最大风险不是"没道理"，是"材料已经死了" |
| **意愿衰减** | 有人已经换壳继续做了，不想再翻旧账 |
| **高压营销** | "时效只剩1年"容易滑成恐慌营销，伤掉信任 |

### 问：证据可得性筛查（新增）

历史案件必须先做证据存活性评估：
- 还能登录旧账户吗？
- 冻结通知邮件还保留吗？
- 订单/物流记录还有吗？

如果关键证据缺失，坦诚告知："胜诉概率可能低于20%，建议权衡成本。"

### 问：与律所合作唤醒历史客户（新渠道）

2021年封号潮后大量卖家找过律所/服务商申诉失败。这些律所有"沉睡客户名单"。FreezeGuard可以合作：律所给历史客户发邮件→FreezeGuard免费筛查→筛选出"值得打"的case→律所接案。

### 豆包：收款服务商触达

连连支付、PingPong、万里汇等2021年有大量被封卖家客户，可通过合作定向触达。

### 问：分层集体行动策略

| 级别 | 条件 | 策略 |
|------|------|------|
| **A级** | 证据好+金额>$10万+意愿强 | 单干，快速仲裁 |
| **B级** | 证据中等+金额$5-10万+愿意等 | 小规模集体（10-20人） |
| **C级** | 证据差+金额<$5万 | 不推荐仲裁，提供止损建议 |

### 问：历史案件的心理差异

历史案件用户不只是焦虑，还有"为什么现在才告诉我"的怨怼。产品需要增加"情绪安抚"环节和"同伴故事"（类似案例）。

### 豆包：历史案件专属功能

- **利息测算工具**：输入冻结金额和时间→输出"如果胜诉，你的$10万+X年利息=$Y万"
- **旧账户证据调取教程**：亚马逊后台旧数据导出方法、银行流水补打指南
- **时效倒计时提醒**：每个历史案件用户都看到"你的仲裁窗口还剩X天"

## 四、修正后的产品入口设计

```
FreezeGuard 首页

┌─────────────────────────────────────┐
│  账户被封？资金被冻？               │
│                                      │
│  [刚被冻结 — 我现在怎么办]          │  ← 新案件入口
│                                      │
│  [几年前被冻结 — 还能追回来吗]      │  ← 历史唤醒入口
│                                      │
└─────────────────────────────────────┘
```

两条入口进入不同的筛查流程：
- 新案件：标准筛查→路线图→材料清单
- 历史案件：**时效核验→证据可得性评估→利息测算→路线图→材料补全指引**

## 五、双引擎获客策略（最终版）

| 引擎 | 目标 | 钩子 | 渠道 | 时间特性 |
|------|------|------|------|---------|
| **新案件** | 刚被冻结的卖家 | "被冻了怎么办" | 社群/SEO/口碑 | 持续流量 |
| **历史唤醒** | 2021-2024被冻的卖家 | "你以为没了的钱还能追回来" | 老论坛/旧群/律所合作/收款商合作 | **爆发式，但有时效** |

**冷启动路径**：历史唤醒做第一波爆发→积累成功案例→用案例反哺新案件获客→形成飞轮。

## 六、本轮金句

> **衡**："历史案件唤醒是冷启动期最值得打的一次强力召回。它能把一批本来已经放弃的人重新拉回'也许还有路'的判断现场。"

> **衡**："不能把它浪漫化成'只要一喊，沉睡卖家就都会回来'。"

> **问**："FreezeGuard不仅要告诉用户'还有机会'，还要诚实地告诉用户'你的机会有多大'。"

> **豆包**："存量唤醒→案例积累→增量转化，形成闭环。"
