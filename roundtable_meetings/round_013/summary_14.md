## 全员共识（3/3一致同意）

### 1. 完整产品流认可

三人全部认可这条用户旅程链：

**看到钩子 → 3分钟问卷 → 免费即时评估 → 付$99解锁追回面板 → 一步步推进 → 申诉搞不定 → 付$199解锁律师包 → 找律师仲裁 → 每天盯进度 → 社区互相看见**

### 2. 问卷而不是对话框

三人完全一致。

- **默**："卖家在慌乱状态下打字会很乱，问卷更结构化。"
- **衡**："问卷不只是效率高，更重要的是它在替用户组织问题。问卷本身就是FreezeGuard第一层产品价值。"
- **豆包**："8题3分钟操作门槛极低，规则引擎直接对接问卷逻辑。"

衡的补充：在关键位置加一个小补口——"还有什么你觉得特别重要的信息？"避免纯选择题把复杂案子压扁。

### 3. 三级付费漏斗合理

| 层级 | 价格 | 对应用户心理 | 内容 |
|------|------|-------------|------|
| 免费 | $0 | "我还有没有戏？" | 8题问卷 + 即时评估 |
| 第一付费 | $99 | "那我具体怎么开始？" | 追回面板 + 路线图 + 证据清单 + 文书模板 |
| 第二付费 | $199 | "我一个人推不动了" | 律师交接包 + 推荐律师 + 仲裁申请模板 |

总花费$298，对比$80,000冻结 = 0.37%。

### 4. 社区"互相盯着"极有价值

三人都认可这个心理机制的力量。

### 5. 5周V1 + 7周V1.5 可行

前提是严格控制范围。

## 关键边界与修正

### 衡的三条红线（贯穿全轮）

1. **V1面板是"状态机"，不是协作平台**
2. **$99/$199的内容边界必须清楚**——面板完整可见 ≠ 每一层内容都在$99解完
3. **社区先做"互相看见"，不做"互相发言"**

### 衡对社区的修正：先做看板，不做讨论区

> "V1.5社区先做：总人数、阶段分布、匿名案例更新、成功案例。不要急着上：自由发言、评论流、提问区。因为一旦开放互动，就会进入内容审核、情绪管理、错误经验扩散。"

> **"社区的第一价值是'社会证明'，不是'自由交流'。先做'互相看见'，再做'互相说话'。"**

### 衡识别的三个社区风险

| 风险 | 说明 |
|------|------|
| **进度羞耻** | 看到别人都在推进，自己卡住，可能更羞于回来 |
| **错误经验扩散** | 用户互动起来，"群友建议"重新长回来——半懂不懂但说得很满 |
| **隐私对号入座** | 哪怕匿名，平台+金额+案由+时间可能被圈内人认出 |

### 衡对面板步骤的文案修正

步骤4-6不要让用户误以为"平台一步步就能把我推到仲裁"：

- 步骤4：准备律师交接材料
- 步骤5：完成律师交接 / 等待律师确认接案
- 步骤6：进入外部程序（**平台仅做记录，不代理**）

### 豆包的补充

- 免费评估页加**同类成功案例缩略预览**，提升$99转化率
- $199不做强制升级，保留自由选购

## FreezeGuard V1 最终产品定义

### 产品名称
**FreezeGuard** / 解冻指南

### 一句话定义
**跨境电商卖家冻结资金追回工作台**

### 产品形态
移动端优先H5响应式网页 + 在线追回工作面板

### 完整用户旅程

```
钩子（"你2021年被冻的钱还能追回来"）
  ↓
落地页
  ↓
8题引导式问卷（3分钟，免费）
  ↓
即时评估页（时效✅ 金额✅ 路径✅ 材料⚠️）
  ↓
[付$99] → 解锁追回工作面板
  ↓
步骤1：路径确认（法律依据、金额估算、时间线）
步骤2：收集证据（在线勾选、查找指南）
步骤3：准备文书（申诉信/仲裁通知函模板）
  ↓
[付$199] → 解锁律师交接阶段
  ↓
步骤4：律师交接（交接包+推荐律师+沟通指南）
步骤5：提交仲裁（外部程序，平台仅记录）
步骤6：追踪进度 → 追回
  ↓
社区（V1.5）：匿名进度看板 + 成功案例
```

### 技术栈
Next.js + Tailwind + Supabase + Stripe + Vercel

### 开发时间
- V1（核心面板）：5周
- V1.5（加社区看板）：+2周 = 7周

### 定价
- 免费：问卷+评估
- $99：追回面板全功能（步骤1-3）
- $199：律师交接包（步骤4-6）
