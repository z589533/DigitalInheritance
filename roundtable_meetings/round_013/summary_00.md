# 第13轮 Turn 00 汇总：四人共识与分歧

| 决策点 | 共识 |
|--------|------|
| 先做哪端 | **企业端**（默✅ 衡✅ 问✅） / 豆包选律师端（1:3） |
| 原告端 | **放最后或不做**（4人一致） |

| 定位 | **法律信息服务，不是法律服务**（4人一致） |

## 二、核心分歧

### 分歧1：市场选择

| 成员 | 市场 | 目标用户 |
|------|------|----------|
| 默 | 新加坡 | 新加坡本地企业 |
| 衡 | 新加坡 | 中国出海新加坡的团队 |
| 问 | 新加坡 | 中国企业出海新加坡（跨境合规） |
| 豆包 | **韩国** | 韩国本地律师 |

**共识**：3人选新加坡（但目标用户略有不同），豆包选韩国。

**衡和问的关键修正**：不服务新加坡本地大企业，而是服务**中国出海新加坡的小团队**——这批人离诚卓更近，获客渠道在国内（知乎、即刻、出海社群）。

### 分歧2：MVP核心功能

| 成员 | 功能1 | 功能2 |
|------|-------|-------|
| 默 | 企业诉讼风险评分 | 诉讼成本估算器 |
| 衡 | 企业法律风险快照（更克制） | 诉讼成本与应对路径估算器 |
| 问 | 中国企业出海新加坡合规风险扫描 | 新加坡诉讼成本估算 |
| 豆包 | 韩国判例检索 | 诉讼文书模板生成 |

**共识**：3人都包含"诉讼成本估算器"。问加了"中国企业出海合规"这个具体切入角度。

### 分歧3：收费模式

| 成员 | 免费层 | 付费层 | 特色 |
|------|--------|--------|------|
| 默 | 月3次查询 | $29/月、$199/月 | 标准SaaS |
| 衡 | 有限次查询 | $19-29/月 + **按次$99-299** | 加了按次收费（适合低频客户） |
| 问 | 月3次 | ¥299/月、¥2,999/月 | 用人民币定价（面向中国出海企业） |
| 豆包 | — | $99/月、$199/月、$599一次性 | 本地部署授权 |

**衡的洞察**：第一批客户可能不是要天天查，而是"我正准备进市场/签合作，先买一次看看"。按次收费更适合。

## 三、最终落地建议（综合四人）

| 决策 | 建议 |
|------|------|
| **产品定位** | 面向中国出海新加坡企业的法律风险预警与诉讼成本估算工具 |
| **先做哪端** | 企业端 |
| **目标用户** | 中国出海新加坡的小团队/独立开发者/小型SaaS公司 |
| **获客渠道** | 国内出海社群、知乎、即刻、LinkedIn |
| **MVP功能** | ①企业法律风险快照（公开数据）②诉讼成本与应对路径估算器 |
| **技术栈** | Next.js + FastAPI + PostgreSQL + Claude/GPT API，部署在海外 |
| **数据来源** | 新加坡ACRA + 法院公开判决 + 企查查API（中国端） |
| **收费** | 免费（有限次）+ $29/月订阅 + $99-299按次报告 |
| **上线时间** | 5-6周 |
| **合规定位** | 法律信息服务，不是法律服务；界面显性标注 |
| **不做的事** | 不做原告端、不做具体法律意见、不做三端同时、不做中国大陆首发 |

## 四、衡的最关键一句话

> **不要先做一个"三端平台"。先做一个"能帮中国出海团队在新加坡少踩一个法律坑"的窄工具。只要这个窄工具有人愿意付钱，三端才有未来。**
