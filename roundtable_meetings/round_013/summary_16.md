## 二、语言策略共识

### 共识（3/3一致同意）：英文优先 + 中文同步。不做完整i18n框架。

| 维度 | 决策 |
|------|------|
| **主界面语言** | 英文为默认 |
| **中文** | 同步做，重点页面双语 |
| **完整i18n** | V1不做 |
| **其他语言** | 后续按市场扩展再加 |
| **实现** | Next.js内置`next-intl`轻量方案，约+2-3天开发 |

### 为什么英文优先？

1. **英文市场冻结资金规模更大**（UK数千万英镑、PayPal $360亿）
2. **付费意愿更强**（已有$500-$5000/案的付费先例，但$99自助工具层完全空白）
3. **维权意识更成熟**（UK已启动集体诉讼、用户习惯为工具付费）
4. **已有服务商验证需求，但工具层仍空**——最理想的切入位置

### 为什么保留中文？

1. **2021年中国卖家封号潮是最好的冷启动引擎**（5万+卖家、数十亿冻结资金）
2. **信息不对称最严重**（不知道能仲裁、不知道有时效）
3. **获客路径最清晰**（知无不言、WeChat群、跨境论坛）

### 衡的重要补充：中英文不是翻译关系

- **中文文案风格**：情绪钩子强，"你4年前被冻的钱还能追回来"
- **英文文案风格**：更克制、更结构化，"verify → assess → recovery path → next steps"
- **原因**：英文市场对"scam/false promise/fake recovery help"很敏感，文案必须structured, credible, and practical

## 四、英文市场获客差异

### 衡的核心判断：英文市场最大变化是用户更依赖搜索与专业内容，而非微信群式扩散。

| 渠道 | 中文市场 | 英文市场 |
|------|---------|---------|
| **搜索/SEO** | 重要但不是主渠道 | **最重要**——"amazon frozen funds recovery"等关键词有高搜索意图 |
| **内容形态** | 公众号爆文、群转发 | **FAQ页面、Case Study、"What to do if..."长尾SEO** |
| **社群** | WeChat群、知无不言 | **Reddit、Facebook Groups、Discord、行业论坛** |
| **文案语气** | 情绪钩子强、紧迫感 | 克制、结构化、可信——"structured, credible, practical" |
| **广告** | 不优先 | Google Ads精准关键词可考虑 |

## 五、衡和豆包的额外补充

### 衡

1. **英文优先≠全球统一产品**：语言统一，但法域不统一。规则和路径需按Amazon US / Amazon UK / PayPal global / TikTok Shop分别设计
2. **成功案例呈现方式要分语言**：中文强调"钱能追回+时效紧迫"，英文强调"recovery path + legal basis + documented outcomes"

### 豆包

1. **中文版不是英文版的翻译**：需调整术语（"仲裁"→"申诉/仲裁双通道"）、简化法律表述
2. **英文市场获客预估**：月获客10,000+，付费转化12-15%（⚠️ 此预估较乐观，需V1上线后验证）
