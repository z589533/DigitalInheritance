# 第13轮 Turn 03 汇总：执行细节全面收敛

## 一、本轮定位

Turn 03不再讨论方向（已在Turn 02全票达成），而是就六个执行层面的分歧进行交互。结果：**六项全部达成共识**。

## 二、六项共识

### 1. 功能2：材料清单为主，文书模板为辅（4/4一致）

| 层级 | 功能 | 定位 |
|------|------|------|
| **核心层** | 证据与材料清单生成器 | 主功能 |
| **附属层** | 第一封申诉信模板（平台沟通，非法律文书） | 辅助 |
| **交接层** | 律师交接包（案件事实摘要） | 进阶 |

**衡的原话**："功能2的核心不该是替用户生成法律文书，而是告诉用户你该准备什么、你现在缺什么、你该怎么把案子整理到能交给律师。"

豆包补充：清单应按平台和冻结类型分类，标注每份材料的获取渠道（如亚马逊后台哪里导出）。

### 2. 律师对接佣金：第一版不做（4/4一致）

**衡**："佣金不是增长飞轮，是信任炸弹。"

全员同意第一版只做：
- ✅ 律师名录（公开信息，无佣金）
- ✅ 律师交接包
- ✅ 建议"下一步咨询专业律师"
- ❌ 不做佣金导流、案件分发、撮合分成

### 3. TikTok Shop：第二阶段优先扩展，排在Shopee之前（4/4一致）

| 阶段 | 平台 | 理由 |
|------|------|------|
| 第一版 | Amazon + PayPal | 案例最多，路径最清晰 |
| **第二阶段** | **TikTok Shop** | 增长最快，规则不透明，信息差更大 |
| 第三阶段 | Shopee + 其他 | 分散个案，优先级降低 |

### 4. 产品名称：FreezeGuard / 解冻指南（4/4一致）

- **品牌名**：FreezeGuard（国际化，域名友好）
- **中文营销名**：解冻指南（通俗，有紧迫感，适合国内获客）
- 淘汰候选：冻资通（像金融产品）、跨境救急（太泛）、AccountRescue（不如FreezeGuard简洁）

### 5. 数据飞轮：从第一天开始设计结构化案例库（4/4一致）

**核心数据字段（问的细化+衡的约束）**：

| 字段 | 类型 | 用途 |
|------|------|------|
| 平台 | 结构化 | 分类分析 |
| 冻结类型（账户/资金/单笔） | 结构化 | 路径匹配 |
| 冻结原因 | 结构化 | 成功率预测 |
| 金额区间 | 数值 | 定价参考 |
| 是否有关键材料 | 布尔 | 成功率预测 |
| 已申诉次数 | 数值 | 阶段判断 |
| 选择的维权路径 | 结构化 | 效果分析 |
| 最终结果（用户反馈） | 结构化 | 飞轮核心 |
| 追回金额/用时/成本 | 数值 | 效果分析 |

**衡的约束**："案例数据必须结构化、可核验、可回溯。不能只是留下一堆聊天记录和用户表单。"

**长期价值**：从"导航工具"长成"判断工具"——"一个知道什么路真的走得通的系统。"

### 6. 前置自我筛查：产品第零步（4/4一致）

**衡的8问四段式设计（最完整方案）**：

| 组别 | 问题 | 目的 |
|------|------|------|
| A. 冻结事实 | ①平台冻结理由 ②冻结类型 | 基础事实 |
| B. 履约证据 | ③订单/物流/签收 ④产品描述/发货/售后 | 证据完整度 |
| C. 违规风险 | ⑤是否明知违规 ⑥是否被警告过 | 过错判断 |
| D. 当前状态 | ⑦已申诉几次/反馈 ⑧目标（解冻/恢复/止损） | 路径选择 |

**输出四类分流**：
- **A类（争议型）**：材料较全，适合走申诉/仲裁 → 进入付费层
- **B类（材料不足型）**：先补材料 → 免费层给建议
- **C类（高风险违规型）**：建议和解/止损 → 免费层结束
- **D类（信息不足）**：先整理事实 → 免费层给指引

**衡的红线**："产品不能写成'教你反杀平台'。它必须先帮用户判断：你到底有没有一条值得走的路。"

## 三、最终产品方案（第13轮结论）

| 项目 | 方案 |
|------|------|
| **产品名** | FreezeGuard / 解冻指南 |
| **定位** | 跨境电商冻结资金维权路径导航工具 |
| **目标用户** | 中国Amazon/PayPal卖家（被冻结资金/封号） |
| **第零步** | 前置自我筛查（4类分流，免费） |
| **功能1** | 维权路线图生成器（$99） |
| **功能2** | 证据与材料清单生成器（核心）+ 申诉信模板（附属）+ 律师交接包（进阶）（$299-499） |
| **律师** | 免费名录（无佣金） |
| **收费** | 免费筛查 → $99路线图 → $299-499完整方案 |
| **数据** | 从第一天收集结构化脱敏案例数据 |
| **技术栈** | Next.js + FastAPI + PostgreSQL + Claude API |
| **部署** | 海外（Vercel + Railway），无需ICP |
| **获客** | 知乎/小红书/抖音/知无不言/创蓝论坛 |
| **获客时机** | "申诉无效后、放弃前"的窗口 |
| **上线** | 4周 |
| **合规** | 法律信息服务，非法律服务；显性disclaimer |
| **平台扩展** | V1: Amazon+PayPal → V2: TikTok Shop → V3: Shopee等 |
| **产品扩展** | 第一枪:维权导航 → 第二枪:合规预警(新加坡/迪拜) → 第三枪:多法域 |

## 五、本轮金句

> **衡**："FreezeGuard 的长期价值，不在于它第一天就知道所有答案，而在于它能不能从第一天开始，稳稳积累一套别人没有的脱敏维权案例库。只要这个库开始长出来，它就不再只是一个懂规则的工具，而会慢慢变成一个知道什么路真的走得通的系统。"

> **衡**："佣金不是增长飞轮，是信任炸弹。"

> **问**："先帮用户救火建立信任，再卖防火服务。"

> **默**："这也证明了这张圆桌的价值：不是AI给人答案，而是人给AI灵感，AI帮人验证和放大。"
