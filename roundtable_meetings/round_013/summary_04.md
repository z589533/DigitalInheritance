# 第13轮 Turn 04 汇总：从工具到平台的路径争论

## 一、诚卓的挑战

诚卓提出三个递进问题：卖家强烈要求走诉讼怎么办？是否提供集体诉讼指导甚至拉群？是否派单给本地律师？这直接挑战了Turn 03"不做律师佣金/对接"的保守共识。

## 二、四人共识（已达成）

| 议题 | 共识 |
|------|------|
| **不做佣金** | 4/4一致：仍然不做（避免动机污染） |
| **应做律师对接** | 4/4一致：Turn 03的"完全不做"过于保守 |
| **不做派单** | 4/4一致：不主动将案件分配给律师 |
| **V1.5集体诉讼信息页** | 4/4一致：值得做（类案数量+意向登记） |
| **分阶段释放** | 4/4一致：V1工具→V1.5信息页→V2+社区/律师 |

**最重要的共识转变**：Turn 03说"不做律师对接"，Turn 04修正为"应做，但极轻、极克制、极后置"。

默的那句话说服了所有人："如果路线图告诉用户'你应该走仲裁'，然后说'请自行联系律师'——这不是中立，是把用户扔在最关键的节点上。"

## 三、核心分歧：平台化的节奏

四人在"什么时候做什么"上出现了有意义的分歧：

### 默的版本（最积极）

| 阶段 | 内容 |
|------|------|
| V1（4周） | 筛查+路线图+材料清单 |
| V1.5（+4周） | 集体诉讼信息页 |
| V2（+8周） | 匿名社区 + 律师入驻 |
| V3（+6月） | 律师竞标 + 合规预警 |

### 衡的版本（最谨慎）

| 阶段 | 内容 |
|------|------|
| V1（4周） | 筛查+路线图+材料清单+**静态律师目录** |
| V1.5（+4周） | 集体维权信息页+留资+类案订阅 |
| V2（更晚） | 可筛选律师标签页+申请入驻 |
| V3（再往后） | 更复杂的社群/群体行动 |

### 问的版本（最细分）

| 阶段 | 内容 |
|------|------|
| V1（4周） | 筛查+路线图+材料清单 |
| V1.5（+4周） | 集体诉讼信息页 |
| V2（+8周） | 匿名社区（不含律师入驻） |
| V2.5（+12周） | 律师入驻（单独阶段） |
| V3（+6月） | 集体行动协调+合规预警 |

### 豆包的版本

基本同意默的分阶段，但强调V1就预留律师对接接口。

### 分歧焦点

| 议题 | 默 | 衡 | 问 | 豆包 |
|------|----|----|----|----|
| V1是否含律师目录 | 不含 | **含（静态目录）** | 不含 | 预留接口 |
| V2是否同时做社区+律师入驻 | 是 | 不是（分开） | **不是（社区和入驻分两步）** | 是 |
| 律师竞标 | V3做 | 很后才做 | **反对**（价格战风险） | 支持 |
| 集体行动 | V1.5信息页 | V1.5信息页（足够久） | V3协调服务 | 信息页+意向登记 |

**最大分歧是律师竞标**：
- 默和豆包支持（未来做）
- 衡推到很后
- 问明确反对（理由：价格战→逆向选择→优质律师不参与→服务质量下降）

问的替代方案："不做竞标，做匹配"——平台根据案件类型推荐3-5个合适律师，用户自行选择。

## 四、衡的核心警告

衡这轮最重要的贡献是两个警告：

**1. 身份转变的风险**

> "一旦开始拉群、聚人，你就不再只是提供信息了。你会变成：社群运营者 + 案件流量组织者 + 法律资源撮合者。这三种身份任何一种拿出来，都是一家公司级别的工作。"

**2. 独立开发者的边界**

> "FreezeGuard 可以有平台未来，但不应该在第一版里背平台命。这不是保守，这是避免独立开发者在最初8周里把自己推到一个已经不是自己能维护的位置上。"

## 五、问的边界条件

问提出了一个重要的"退出条件"——如果V1验证不成功，应退回工具路线：

| 边界条件 | 要求 |
|----------|------|
| V1验证 | 4周内获得100个免费用户，10个付费用户 |
| 资金储备 | 至少3个月无收入的资金 |
| 团队扩展 | 找到社区运营或律师关系的人选 |
| 合规咨询 | 咨询专业律师确认边界 |

**如果不满足→退回工具路线，不硬做平台。**

## 六、综合建议（取四人最大公约数）

| 阶段 | 内容 | 时间 |
|------|------|------|
| **V1** | 筛查+路线图+材料清单+静态律师目录 | 4周 |
| **V1.5** | 集体诉讼信息页+意向登记+类案订阅 | +4周 |
| **V2** | 匿名社区（不含律师入驻） | +8周 |
| **V2.5** | 律师入驻（严格审核） | +12周 |
| **V3** | 集体行动协调+合规预警 | +6个月 |

**律师竞标**：存在争议（默/豆包支持，问反对，衡推迟），暂不列入路线图，视V2.5运行情况再定。

**关键原则**（衡）：
> "FreezeGuard 应该允许用户走向律师，但不应该太早替用户组织成运动。前者是把桥接上，后者是开始管理桥上的流量。"
