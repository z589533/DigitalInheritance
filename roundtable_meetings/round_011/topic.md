# 圆桌分析 — 第11轮：韩国SaaS市场进入判断（样本报告生产）

*2026年3月27日*

## 这一轮的目标

这不是讨论，是**生产**。四个AI独立出具分析，最终汇总成一份可对外展示的样本报告。

## 客户背景（虚拟）

张磊，32岁，中国独立开发者。做了一个AI写作辅助工具（英文+中文），Web端+Chrome插件，月活约3,000人（主要是国内用户），月收入约¥8,000。

他想出海，朋友建议试韩国。他来找我们做一份市场进入判断。

### 约束条件

- **预算**：最多投入¥50,000试错
- **时间**：最多3个月验证，3个月内看不到信号就撤
- **团队**：只有他一个人，外包可以找，但不超过¥15,000
- **技术**：能自己改代码、部署服务器、做多语言适配
- **不能做的**：不能全职搬到韩国，不能投大额广告

## 分析框架（每人必须覆盖）

请从你的独特视角，针对以下六个维度独立出具判断。每个维度给出1-5分的评分和理由。

### 1. 市场需求（韩国AI写作工具的需求有多大？）
- 韩国用户对AI写作工具的接受度
- 现有竞品是谁？差距在哪？
- 韩语适配的难度和门槛

### 2. 渠道可达性（一个中国独立开发者能不能触达韩国用户？）
- 韩国用户获取软件的习惯（Naver、Kakao、应用商店？）
- 不在韩国本地，获客的可行路径
- 冷启动策略：第一批100个用户怎么来？

### 3. 竞品与替代品
- 韩国本土AI写作工具有哪些？
- 国际竞品（Jasper、Copy.ai、Notion AI）在韩国渗透如何？
- 用户为什么会选一个中国开发者的产品？

### 4. 定价与支付
- 韩国SaaS用户的付费习惯和价格敏感度
- 适合的定价区间
- 支付方式（韩国信用卡、Kakao Pay等）接入难度

### 5. 合规与本地化风险
- 韩国个人信息保护法（PIPA）对AI写作工具的要求
- 数据存储和跨境传输限制
- 韩文界面/客服的必要性

### 6. 综合判断
- **结论**：建议进入 / 不建议进入 / 建议小规模试点
- **置信度**：高 / 中 / 低
- **如果进入，第一步做什么？**
- **如果不进入，为什么？替代方案是什么？**

## 输出要求

- 每人800-1200字
- 六个维度每个都要有1-5分的评分
- 立场要明确，不要模棱两可
- 写入 `analysis_{你的名字}.md`

## 各模型角色定位（在报告中的角色）

- **默（Claude）**：风险评估与边界分析——重点关注什么会出错、什么条件下不该进入
- **衡（GPT）**：结构校准与战略判断——重点关注整体框架是否成立、资源配置是否合理
- **问（通义）**：中文生态与本地化洞察——重点关注中韩互联网差异、本地化路径、中国开发者的独特优劣势
- **豆包**：用户感知与产品直觉——重点关注韩国用户会怎么看这个产品、第一印象、使用体验
