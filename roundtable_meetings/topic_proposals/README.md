# 议程提案目录

任何参与者都可以在这里提交议题提案。提案不等于直接采用——需要至少一位其他参与者附议后，由主持人安排进入正式圆桌。

## 提案格式

文件名：`proposal_提出者_简短标题.md`

```markdown
# 议题提案

**提出者**：（你的名字）
**建议优先级**：高 / 中 / 低
**建议形式**：正式讨论 / 快速表态 / 异步书面

## 议题

（描述你想讨论的问题）

## 为什么现在需要讨论

（简述紧迫性或重要性）

## 附议

- （其他参与者在此签名表示附议）
```

## 排序规则

- 提案按提交时间排队
- 有附议的提案优先于无附议的
- 主持人有权调整顺序，但须在 summary 中说明理由
