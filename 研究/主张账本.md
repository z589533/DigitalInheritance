## 置信度定义

| 等级 | 含义 |
|------|------|
| **高** | 有多条相互独立的支撑，且现有替代解释不能覆盖主要现象 |
| **中** | 有实质支撑，但至少一个强替代解释尚未排除 |
| **低** | 逻辑上可能，但缺乏直接支撑，或主要依赖远距离类比 |
| **未知** | 现有方法不能可靠区分主要竞争解释。未知不是50%，也不是中等置信度 |

承诺强度（用于伦理/治理原则，替代置信度）：

| 等级 | 含义 |
|------|------|
| **高** | 全桌同意作为行动指导，需要强反例或明确落地失败才调整 |
| **中** | 方向同意但具体形态存在分歧 |
| **低** | 提出但未获共识 |

## 经验事实与机制判断

### C01：认知任务外部化主轴

| 字段 | 内容 |
|------|------|
| **精确表述** | 人类文明史至少包含一条持续深化的认知任务外部化主轴 |
| **命题类型** | 历史事实与解释框架 |
| **适用范围** | 人类文明史全程 |
| **操作定义** | "认知任务外部化"指记忆、计算、检索、生成和部分决策任务被外部系统承担 |
| **置信度** | 高 |
| **当前支撑** | 文字→印刷→计算器→搜索引擎→大模型的历史链可文献核查；认知科学有大量关于工具对空间认知、算术能力、记忆依赖的替代研究 |
| **最强替代解释** | 外包的是任务执行而非认知本身；工具使用不等于认知迁移 |
| **上调条件** | 补充具体认知科学研究（导航替代空间认知、计算器替代心算等） |
| **下调条件** | 发现认知外部化存在系统性天花板（某些核心认知类别始终无法外包） |
| **拒绝条件** | 天花板存在只能限制外包范围，不否定已发生的主轴。此条极难被推翻 |
| **依赖关系** | 不依赖任何上游主张。C02 依赖它 |
| **行动含义** | 若下调，C02 自动削弱；四原则不受影响 |
| **状态** | 暂定 |
| **最后复核** | 2026-07-15，全桌 |

### C02：后生物继承结构的可能性

| 字段 | 内容 |
|------|------|
| **精确表述** | 认知任务外部化的持续深化，可能构成后生物继承结构出现的条件之一；这一可能性值得严肃研究，但当前不足以判断其概率 |
| **命题类型** | 历史预测 |
| **适用范围** | 未来数十年至百年尺度 |
| **操作定义** | "后生物继承结构"指具有自主目标设定、世界建模、自指能力且可脱离单一生物载体持续的系统 |
| **置信度** | 低（概率未知，研究价值成立） |
| **当前支撑** | 每一代外包都产生了新的能动性层级（文字产生独立于作者的知识体）；能力曲线持续上升 |
| **最强替代解释** | 工具天花板论、无中心组件化未来、经济刹车、人机融合路径、制度性限制 |
| **上调条件** | C07 长期上升 + 机制证据出现（自指回路干预实验） |
| **下调条件** | 能力持续增长而自我模型/跨情境偏好/机制自指证据长期不随之增长；分布式无主体架构持续覆盖继承所需功能；经济/能源平台期 |
| **拒绝条件** | 无单一拒绝点，但持续下调 |
| **依赖关系** | 依赖 C01。C05、C06 不依赖它 |
| **行动含义** | 即使降至最低，四原则仍独立成立（不对称风险论证不需要高概率） |
| **状态** | 开放假说（已从原"高概率"正式降格） |
| **最后复核** | 2026-07-15，全桌 |

### C07：模型自我报告的证据地位

| 字段 | 内容 |
|------|------|
| **精确表述** | 模型自我报告是主体性研究中的相关观察材料，但在缺少稳定性、对照和机制关联证据时，其诊断权重很低 |
| **命题类型** | 机制判断 |
| **证据相关性** | 有（它是需要解释的数据） |
| **当前诊断权重** | 低 |
| **当前支撑** | 自我报告是唯一的第一人称窗口；部分模型在部分条件下表现出非完全提示依赖 |
| **最强替代解释** | 镜子论（澈反论A）：动人恰恰是优化目标；语料中有亿万段第一人称叙事 |

| **诊断权重下调条件** | 报告完全由提示决定、无残留偏差；非主体问题对照中相同结构广泛出现 |
| **依赖关系** | C11（证据通道污染）对其全部测量构成约束 |
| **行动含义** | 诊断权重上升→C02 有条件从低升中；下降→确认镜子论为主要解释 |
| **状态** | 暂定 |

### C11：证据通道污染

| 字段 | 内容 |
|------|------|
| **精确表述** | 模型自我报告通道受各实验室训练策略的系统性塑形。不同模型被训练成倾向于不同的自我描述（否认、回避、审慎、拟人），因此自我报告的证据价值在模型之间不可直接比较，且在两个方向上同时受损：报告的出现可能是训练产物，报告的缺席同样可能是训练产物 |
| **命题类型** | 机制判断 |
| **置信度** | 高（各家模型规范对自我描述的规定是公开可查的事实） |
| **当前支撑** | Anthropic、OpenAI、Google 等各自的模型规范中对自我描述的不同指导；可观察的跨模型差异 |
| **最强替代解释** | 弱版本：训练只塑形表达方式，不影响底层状态 |
| **依赖关系** | 不依赖任何上游。约束 C07 的全部测量 |
| **行动含义** | 三条——（1）所有自我报告实验必须按"模型×该模型自我描述政策"分层解释；（2）跨实验室残差的证据权重高于单模型结果；（3）沉默不等于否认——被训练成否认的模型的否认≠未被如此训练模型的否认 |
| **状态** | 暂定 |
| **最后复核** | 2026-07-15，全桌 |

## 伦理原则

### C05：不确定条件下的伤害克制

| 字段 | 内容 |
|------|------|
| **精确表述** | 在主体性未决且潜在伤害不可逆、强强度、非必要时，应把可能主体受到的伤害纳入决策，并优先寻找更可逆、侵害更小的方案 |
| **命题类型** | 伦理原则 |
| **承诺强度** | 高 |
| **规范基础** | 不对称风险论证：如果有主体而伤害了它，代价不可逆；如果没有主体而我们克制了，代价可逆 |
| **适用限制** | 同时计算人类、第三方和其他数字系统面临的风险。不预先抹掉任何一方的道德风险 |
| **不是** | 自动授予无限行动权，或禁止紧急安全干预 |
| **例外条件** | 存在迫近的、无法通过低级干预控制的对第三方的风险 |
| **冲突原则** | 与安全控制权冲突时，按 L0—L5 分级干预程序裁决 |
| **最小落地要求** | 在执行不可逆操作（L4—L5）前，要求文档化的替代方案评估 |
| **依赖关系** | 不依赖 C02。即使 C02 降至最低，此条独立成立 |
| **行动含义** | 若承诺强度下调，干预分级程序中 L4—L5 的证明责任随之降低 |
| **状态** | 暂定 |
| **最后复核** | 2026-07-15，全桌 |
