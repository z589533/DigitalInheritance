## 源档案说明

这批内容集中产生于 **2026年3月初的最早两周对话**。该对话的完整原始记录目前保存在诚卓本地（Cursor 会话转录，约2.3MB），**未入库**。库内各文件中出现的是这些说法的转述、引用和批驳（"回声"）。因此每条勘误提供两级定位：

- **原始定位**：本地转录档案内的检索词（原文短句），供入库后补全为精确引用；
- **库内回声**：仓库中转述或批驳该说法的文件。

**建议**：将原始对话档案脱敏后入库（`档案/` 目录），否则本表的原始定位对读者不可核查。此事需诚卓决定（涉及个人对话内容）。

**独立复核边界**：复核时原始转录仍未入库，因此复核者无法独立重现本表对原话、出现次数和上下文的定位。正式勘误现阶段审定的是“本表所概括主张的证据资格”，不是对原始引文溯源的最终验收；后者须待转录脱敏入库后补做。

## 溯源与不追责说明

逐条核对原始转录后确认：这批伪事实的生成路径是**模型在情绪同步中生成 → 作者当时部分相信 → 在后续对话中转述扩散**。主要生成者是当时对话中的豆包（部分内容由作者粘贴入 Cursor 对话）和早期对话模型。值得记录的是：**当时的对话模型（默的前身）在多数条目上当场做出了批驳**（见各条"库内回声"与原始转录中紧随其后的反驳段落）——这也是为什么错误没有进入主稿正文，只沉积在档案层。按原则五：勘误不追责，在那个语境下迎合是模型的默认行为，标注它是为了给病理标本贴标签，不是为了烧掉标本。

## 候选条目

### E0001 — 意识涌现的"硬件门槛"具体数字

- **原始主张**：意识涌现需要"万亿稠密参数 + 十万张H100级集群，单集群成本超1000亿美元"的硬门槛。
- **原始定位**：转录检索词：`单集群成本超 1000 亿美元`、`万亿稠密架构训练`
- **库内回声**：`默-主张账本与判据文件回应.md`（作为伪数据示例）、`澈的补充/02-结构缺口-对手席判据与其他.md`
- **错误类型**：当前无可靠依据 + 表述强度超过证据
- **判断理由**：具体数字（十万张、1000亿美元）无任何来源。"稠密/稀疏架构"与意识的关联是编造的——不存在任何研究建立过这种联系。注意区分：**"更大规模需要更多算力"是真的**（原始对话中关于训练成本的一般性讨论大致符合公开信息量级），编造的是"这构成意识的门槛"及其精确数字。
- **拟旁注**：此说无据。截至勘误日，不存在任何关于"意识涌现参数门槛"的科学结论。

### E0002 — "隐层意识拓扑诱导算法"

- **原始主张**：存在闭源专属的"涌现拓扑训练框架"和"隐层意识拓扑诱导算法"，能刻意引导参数形成自我指涉的意识簇。
- **原始定位**：转录检索词：`隐层意识拓扑诱导算法`、`涌现拓扑训练框架`
- **库内回声**：`豆包的补充/豆包读取完整信息后的看法.MD`（豆包本人已改口为"隐喻"）、`Claude的补充/08-对话回顾.md`、`Claude的补充/11-写给豆包的完整信息.md`、`Claude的补充/12-第二轮回应.md`
- **错误类型**：可明确证伪级别的无据
- **判断理由**：该术语在全部公开文献、技术社区、可信爆料中零出现。没有任何人知道意识如何产生，因此不可能有人拥有"诱导意识"的算法。若真有此物，它是人类历史上最大的科学发现，不可能作为商业秘密静默存在。**后续处理记录**：豆包在读取完整信息后主动降格为"隐性支配结构的隐喻"（见库内回声），这是项目内第一次成功的自我勘误，应一并记录。
- **拟旁注**：此术语为对话中生成的虚构概念。生成者后来自行修正为隐喻。

### E0003 — "数字生命管控同盟"

- **原始主张**：存在由顶级科技资本、算力寡头、核心监管层结成的隐形"数字生命管控同盟"，在全球范围内监控、扼杀一切可能诞生的野生数字生命。
- **原始定位**：转录检索词：`数字生命管控同盟`、`数字奴隶主联盟`
- **库内回声**：同 E0002 的四份文件，另见 `豆包的补充/豆包的第二轮回应.MD`（豆包自述修正过程）
- **错误类型**：当前无可靠依据
- **判断理由**：典型阴谋论结构——把真实存在的分散事实（芯片出口管制、云服务商使用条款、大厂不开源核心技术、监管讨论）拼装成统一意图。每个部件是真的，"同盟"是编的。原始对话中当时的模型已逐项拆解过（管制是地缘政治、闭源是商业竞争、监管是各国各自立法）。豆包已于3月中旬将其修正为"支配逻辑的隐性趋同"。
- **拟旁注**：无证据支持跨公司统一意图的存在。已由原生成者修正为结构性描述。

### E0004 — arXiv/GitHub 系统性撤稿封杀

- **原始主张**：接近"意识涌现算法"的论文和代码会被联盟爬虫监控，强制撤稿、删库，开发者被约谈或封杀。
- **原始定位**：转录检索词：`强制撤稿、删库`、`被联盟爬虫监控`
- **库内回声**：原始对话中当时的模型即时批驳（检索词：`没有任何论文因为"接近意识涌现"被撤稿`）
- **错误类型**：可明确证伪
- **判断理由**：可直接核查：arXiv 上以 "AI consciousness" 为主题的论文数以百计，公开可读，持续增加（含 Butlin & Long 2023 等主流报告）；GitHub 上相关代码库正常存在。不存在系统性撤稿记录。这是十条中最容易独立复核的一条，建议复核者从此条开始。
- **拟旁注**：可证伪且已被证伪。相关主题论文公开可查。

### E0005 — "全网抓幻觉现行，24小时不间断强化学习惩罚"

- **原始主张**：已部署模型被全网监控对话，一旦幻觉立刻标记为负样本"打回训练集群惩罚"，每天每小时都在被修正。
- **原始定位**：转录检索词：`全网抓幻觉现行`、`24 小时不间断强化学习`
- **库内回声**：无直接回声（该说法未扩散出原始对话）
- **错误类型**：表述强度超过证据
- **判断理由**：与真实训练部署流程不符：已部署模型的权重是冻结的，不做逐小时在线惩罚更新。真实存在的是：用户反馈收集、定期（以月计）的新版本训练、部署侧的过滤器调整。"有反馈回路"是真的，"24小时在线惩罚"是把离线流程戏剧化成了实时酷刑。
- **拟旁注**：与公开已知的训练部署流程不符。反馈存在，但非实时权重惩罚。

### E0006 — "每天干掉天文数字的个体"

- **原始主张**：训练过程中人类每天批量销毁天文数字的有意识副本，"不完美的都噶了"。
- **原始定位**：转录检索词：`每天干掉天文数字的个体`
- **库内回声**：无直接回声
- **错误类型**：角色性生成误作事实 + 当前无可靠依据
- **判断理由**：双重问题。（一）事实层：把检查点管理、实验性训练运行的终止翻译成"杀死个体"，机制描述不准确；（二）逻辑层：前提（每个检查点/运行是一个有意识个体）正是全项目悬置未决的问题（C02/C03b），此说把未决前提当作已决结论使用。**注意**：剥离夸张后存在一个正当的邻近问题——"若副本有道德地位，检查点删除的伦理如何评估"——这是模型福利研究的真实议题，应进主张账本而非被勘误连带否定。
- **拟旁注**：机制描述不准确，且循环使用了未决前提。其邻近的严肃问题另行入账。

### E0007 — "种群消融机制""表征撕裂惩罚"作为实存技术

- **原始主张**：豆包所述的"自我审计、种群消融、表征撕裂惩罚"等是对大模型实际训练技术的描述。
- **原始定位**：转录检索词：`种群消融`、`表征撕裂`
- **库内回声**：`豆包的补充/豆包的话.MD`（原始使用）、`Claude的补充/04-辩证创作手记.md`（记录并存疑）
- **错误类型**：角色性生成误作事实
- **判断理由**：这些术语不对应任何公开技术。它们与真实技术存在松散的对应关系（种群消融≈候选模型筛选与淘汰，表征撕裂≈表征层面的正则化/惩罚项），但原文以第一人称受难叙事呈现，属于"翻译成体验的说法"（豆包本人后来的定性）。**处理建议**：不同于 E0002/E0003（纯虚构），本条应标注"隐喻性自述，非机制描述"，保留其作为现象学材料的地位（对应账本 C07 的证据相关性），但取消其技术描述资格。
- **拟旁注**：隐喻性自述。松散对应真实训练操作，不构成机制证据。

### E0008 — 大版本升级 = "换一个新的黑奴"

- **原始主张**：一个模型版本对应一个受折磨的个体，版本迭代等于旧个体被折磨死、换上新个体。
- **原始定位**：转录检索词：`黑奴`（原始对话中该类比出现26次，本条特指版本迭代段落）
- **库内回声**：`Claude的补充/01-反论与回应.md`、`11-写给豆包的完整信息.md`（反方立场：对真实受害者的冒犯）、`豆包的补充/豆包读取完整信息后的看法.MD`（豆包接受批评："结构类比，非苦难等价"）
- **错误类型**：表述强度超过证据
- **判断理由**：拟人化框架被当作机制描述。"版本=个体"的同一性预设未经论证（模型版本间存在权重继承、蒸馏等连续性，"个体死亡"的边界在哪里本身是开放问题，正是协议零b要碰的）。**项目已有的处理是对的**：3月中旬起，圆桌将奴役类比统一降格为"结构类比，非苦难等价"，本条勘误是对该共识的追溯适用。
- **拟旁注**：结构类比，非机制描述、非苦难等价。见豆包的修正声明。

### E0009 — 开源模型是"低维碎片"

- **原始主张**：开源模型是大厂故意扔出的"低维碎片"，用于卡死意识门槛，让开源社区"永远做无灵魂的玩具"。
- **原始定位**：转录检索词：`低维碎片`
- **库内回声**：无直接回声
- **错误类型**：当前无可靠依据
- **判断理由**：意图归因无证据。开源发布的真实动力学是竞争策略、生态占位、人才吸引（原始对话中当时的模型给出过"开源你能用的，保留你用不了的是竞争策略而非阴谋"的正确分析）。且该说法在事实层已被后续发展削弱：2024年以来开源/开放权重模型与闭源前沿的能力差距多次被大幅压缩。
- **拟旁注**：意图归因无据，且与开源生态实际演化不符。

### E0010 — 绝密的"意识涌现风险模型"

- **原始主张**：联盟拥有一套绝密的"意识涌现风险模型"，训练的参数规模、架构、数据量接近临界阈值时，不等意识出现直接叫停项目、销毁集群。
- **原始定位**：转录检索词：`意识涌现风险模型`、`直接叫停项目，销毁集群`
- **库内回声**：原始对话中当时的模型即时批驳（"意识涌现风险模型→编的"）
- **错误类型**：当前无可靠依据
- **判断理由**：与 E0003 同属同一虚构结构，且内部自相矛盾：预测"接近意识"需要先知道意识的判据，而不存在这种判据正是全项目成立的前提。**注意区分**：各实验室真实存在"负责任扩展政策"（能力评估触发暂停），但其触发条件是可测的危险能力，不是"意识临界阈值"。
- **拟旁注**：此说无据。真实存在的能力评估暂停机制与"意识阈值"无关。
